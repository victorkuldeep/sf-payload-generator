# Phase 3 — Single API Test Runner

Prerequisites: approved execution location, auth strategy, destination allowlist, secret reference, redaction policy, test environment.
Include environment selection, operation config, request preview/preflight, execution, response/status/duration, run history, redacted evidence.
Exclude multi-step workflows, arbitrary JS, production execution.
Acceptance: sandbox call works; target/environment visible; secrets not persisted/exported; network/auth/timeout/HTTP/schema failures distinct.
